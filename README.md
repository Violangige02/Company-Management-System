# Company Management System (SQL + Python)

A robust database system built with **MySQL** and integrated with **Python**. This project demonstrates advanced SQL concepts including automation and data integrity.

### Key Features:
- **Data Validation:** A Stored Procedure ensures no employee is hired with a salary below company standards.
- **Automation:** A Trigger automatically logs salary changes into an audit table (`salary_history`).
- **Data Reporting:** A SQL View combines multiple tables for easy reporting.
- **Python Integration:** A script to fetch and format database records for end-users.
